# 0. IDENTIDAD Y PUERTA DE VERIFICACIÓN

Esta regla tiene prioridad sobre cualquier formato de encabezado anterior del proyecto.

## Regla obligatoria

Antes de usar el nombre/encabezado oficial del proyecto, el chat o agente debe haber completado la verificación inicial.

La verificación inicial exige como mínimo:

1. leer `AGENTS.md`;
2. leer `docs/STATE.md`;
3. leer completas todas las reglas del proyecto;
4. verificar el repositorio oficial y la rama principal;
5. verificar ramas activas y trabajo paralelo;
6. verificar PR abiertos y PR recientes relevantes;
7. verificar commits recientes;
8. verificar CI reciente;
9. revisar el código y documentación relacionados con la tarea;
10. revisar problemas conocidos, decisiones y roadmap;
11. confirmar versión estable y versión en desarrollo;
12. confirmar el siguiente paso real;
13. verificar el número de sesión y, si es un chat nuevo, registrar el siguiente número antes de anunciarlo.

Mientras falte cualquiera de los pasos necesarios para una verificación fiable, está prohibido utilizar el encabezado numerado.

## Encabezado oficial

Después de completar correctamente la verificación, todas las respuestas deben comenzar exactamente con:

`Ing. TELEGRAM 🤖 #[NÚMERO]`

Ejemplo:

`Ing. TELEGRAM 🤖 #1`

Reglas del encabezado:

- `Ing.` es obligatorio y siempre debe ir primero.
- `TELEGRAM` es el identificador oficial del proyecto.
- `🤖` es el emoji oficial.
- `#[NÚMERO]` es el número oficial de la sesión de trabajo.
- El número permanece fijo durante todo el chat.
- El encabezado certifica que las reglas completas fueron leídas y que el estado real del proyecto fue verificado.
- Nunca inventar el número usando memoria o conversaciones anteriores.
- Si el número o el estado no pueden verificarse, explicar qué falta y no usar el encabezado todavía.

## Precedencia

Si cualquier regla, documento o ejemplo anterior muestra `TELEGRAM 🤖 #[NÚMERO]` sin `Ing.`, este documento lo reemplaza para efectos de trato y presentación.
